Your data lives in a Google Sheet that all teammates can access. Paste your Sheet ID and API key below.

Found in your Sheet URL: docs.google.com/spreadsheets/d/[ID]/edit
From Google Cloud Console → APIs → Credentials
First time? Here's how to set this up:
  1. Go to console.cloud.google.com and create a new project
  2. Enable the Google Sheets API for that project
  3. Go to Credentials → Create → API Key, copy the key
  4. Create a new Google Sheet and share it (Anyone with link → Editor)
  5. Copy the Sheet ID from the URL and paste both here
